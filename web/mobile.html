Checking telephony…

Calls run through Twilio and are answered by this same Core Agent. A phone number and per-minute call charges are the only paid parts; the gateway itself is local.

  1. Set JARVIS_TELEPHONY_PROVIDER=twilio with the account SID, auth token and Twilio number in backend/.env.
  2. Expose this PC over HTTPS (the existing Tailscale Serve address works) and put it in JARVIS_TELEPHONY_PUBLIC_BASE_URL.
  3. Add your own number to JARVIS_TELEPHONY_ALLOWED_CALLERS.
  4. Point the Twilio voice webhook at {base}/telephony/voice.
